# Add Long-Project Organization

## Summary

Add one kind at a time, each with domain creation profile, catalog-backed renderer, allocator, proposal, preview, safe commit, typed edit operations, commands, and focused acceptance. Epic (lifecycle, task membership, progress), milestone (due date, lifecycle, progress, overdue), task iteration. Optional perspectives only when used or requested. Relationships derived from links, not mirrored arrays.

### Exit gate
