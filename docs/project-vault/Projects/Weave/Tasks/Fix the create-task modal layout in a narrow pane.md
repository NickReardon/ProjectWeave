# Fix the create-task modal layout in a narrow pane

The create-task modal is cramped in a narrow pane. Obsidian's `Setting` rows
keep the label and control side by side at every width, so the descriptions
compress into tall thin columns rather than the control moving below its
label. Reconsider the modal's layout or wrapping; it is awkward, not broken,
and no behavior depends on it.
