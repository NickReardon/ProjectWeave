# Project Weave

Project Weave is a planned Markdown-first project-management plugin for
Obsidian. It will support multiple projects, lightweight agile planning,
dependency-aware tasks, epics, project and portfolio sprints, and links
between execution work and source documents.

The initial product and implementation plan is in [PLAN.md](PLAN.md).

## Current status

Research and planning. No plugin runtime has been implemented yet.
